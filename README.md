# Экономика межгород-трансфера

Мобильный интерактивный калькулятор для оценки заказа до выезда.

## Расчёт

- Общий пробег = подача + поездка с клиентом + обратный путь.
- Топливо = общий пробег × расход / 100 × цена литра.
- Износ = общий пробег × затраты на километр.
- Ожидаемая выручка = прямая поездка + вероятность обратного заказа × обратный путь × тариф обратки.
- Ожидаемая прибыль = ожидаемая выручка − все расходы.
- Минимально выгодный тариф = максимум из базовой ставки класса и ставки, которая покрывает расходы и желаемую прибыль с учётом ожидаемой обратки.

## Проверочные сценарии

В интерфейсе есть три готовых сценария: ближний рейс, аэропорт и дальний рейс.
